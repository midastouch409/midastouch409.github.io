IMPORTANT BEFORE PUBLISHING
1. Replace hello@dailytipshub.example with an email address you actually control.
2. Replace the demo form behavior with a real form/email service if you want messages/subscriptions to be received.
3. Replace any placeholder links and add your real social/profile links if desired.
4. Add your own branding, logo and original images.
5. Read the current Adsterra publisher rules before enabling any ad format.
6. Do not enable adult advertising merely to increase CPM if the site is intended for a general audience.
7. Only submit a website URL that you own/control and that is publicly accessible.

HOSTING
Upload all files in this folder to your web host's public web directory. The homepage is index.html.

ADSTERRA
Once the website is publicly accessible:
- Website: enter the complete public URL.
- Category: select the category that truthfully describes the site's content.
- Adult ads: keep OFF for a general-audience informational site.
- Ad formats: select formats appropriate for your visitors and follow Adsterra's current policies.

NOTE
This is a static website. It does not include a backend/database. The contact and newsletter forms are intentionally demo forms until connected to a legitimate email/form provider.
